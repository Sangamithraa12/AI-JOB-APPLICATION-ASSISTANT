🛡️ Assessment Overview

Created for the Gokul Infocare AI Growth & Automation Associate practical evaluation

The AI Job Application Assistant is an end-to-end, full-stack career automation platform tailored specifically for fresh graduates and early-career job seekers. Rather than a static UI or toy wrapper, it delivers robust backend workflows, mathematical transparency, non-hallucinatory document customization, and local SQLite data sovereignty.

1. Full-Stack Foundation

Python 3, Flask, SQLite with parameterized queries, pypdf text parsing, and responsive CSS/Vanilla JS.

2. Transparent Scoring

Calculated skill coverage formula ($75\%$ required + $25\%$ preferred) explicitly labeled as an alignment tool, never a hiring guarantee.

3. Ethical AI Guardrails

Zero fabrication directives, sandboxed XML delimiter defenses, and a verifiable offline deterministic Demo Mode.

🔒 Privacy & Data Retention Policy

Clear commitments regarding personal resumes and application tracking data

  • Zero Permanent Resume Retention: When you upload a PDF resume, the text is extracted in-memory using pypdf. The temporary file is immediately scrubbed and deleted from the operating system upon extraction.
  • Local SQLite Data Sovereignty: All tracked job applications, URLs, statuses, and notes are stored strictly in your local SQLite database file at database/job_tracker.db. No application data is synced to external telemetry or third-party cloud trackers.
  • Explicit AI Consent & Provider Notice: Resumes and job descriptions are never sent to third-party AI APIs without explicit user action (clicking Generate/Analyze). In Demo Mode, all analysis executes 100% locally on your machine without external network calls.
  • API Key Security: Provider keys (such as GEMINI_API_KEY) reside only in your local .env file, are read server-side, and are never sent to the browser or committed to version control.
